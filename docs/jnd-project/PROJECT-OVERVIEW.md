## Deployment setup

The GitHub repository is connected to the live deployment. The repository's default branch and inspected local branch are both `main`. No GitHub Actions workflow, Pages configuration, `wrangler.toml`, Worker, Netlify file, Vercel file, `_redirects`, or other deployment configuration is tracked here.

The live site is delivered by Cloudflare and its behavior matches Cloudflare Pages. Before the 404 correction, both Home and a deliberately nonexistent path returned the Home document with HTTP 200. Cloudflare Pages documents this as its automatic SPA behavior when deployed output has `index.html` but no top-level `404.html`. The repository now adds `src/pages/404.astro`, Astro builds it to `dist/404.html`, and fresh unknown production paths return the branded page with HTTP 404.

Four previously visited starter URLs remained available from a shared cache after deployment: `/about/`, `/blog/`, `/blog/first-post/`, and `/rss.xml`. Exact responses advertised `Cache-Control: public, s-maxage=604800` with nonzero `Age`, while cache-busted requests returned the correct new 404. The current source/build is correct; the remaining dashboard-side requirement is to purge these exact URLs in Cloudflare or allow their seven-day shared-cache lifetime to expire. No Cloudflare cache or setting was changed during this task. Exact account-side build settings remain unverified.

Current production-correctness settings:

- `astro.config.mjs` sets `site` to `https://justneedsdone.com`.
- Static output includes top-level `404.html` and no repository catch-all rewrite.
- The sitemap integration remains enabled.
- The connected production branch, build command, output directory, environment variables, and any dashboard-side routing rules should be confirmed in Cloudflare without changing them unless a remaining issue is proven.

The former `/about/`, `/blog/`, five demo-post routes, and `/rss.xml` were removed because they contained only unapproved Astro starter material. They are not linked, generated, or included in the sitemap.

## Shared layouts and components

- `src/layouts/Layout.astro` provides `BaseHead`, a skip-to-content link, `Header`, a slotted `main`, and `Footer` for all five current HTML pages.
- `src/components/BaseHead.astro` imports global CSS, loads the approved Oswald/Inter fonts, and produces production-domain canonical, Open Graph, and Twitter metadata plus favicon and sitemap links.
- `src/components/Header.astro` provides the JND logo, primary navigation, and inline Facebook icon.
- `src/components/HeaderLink.astro` calculates active navigation state and exposes it with `aria-current="page"`.
- `src/components/Footer.astro` provides copyright, tagline, and email.
- `src/styles/global.css` provides the approved colors, fonts, approximately 1100px inner content shell, responsive gutters, reusable hero/button/card/panel patterns, keyboard focus, and reduced-motion rules.
